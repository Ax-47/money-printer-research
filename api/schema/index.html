    money_printer_research.schema ¶

    Column names, dtypes and descriptions of every frame, as pandera models, by entity.

    match/        one row per match: the Understat schedule, Transfermarkt games,
              and the pre-match features joined onto them
player/       one row per player per match: Understat player stats and load
club/         the Transfermarkt club -> Understat team map, and each club's calendar
competition/  Transfermarkt competitions and how they are grouped (COMP_TYPES)
bet/          the backtest: each game's odds and pick, and how its strategies did

    Inside each entity, one module per stage, in pipeline order (an entity has only the stages it needs):

    raw.py        every column of a collected file; collected.py explains raw vs selected
selected.py   the raw columns the clean pipeline reads
clean.py      cleaned frames, written as CSV to settings.clean.out_dir
features.py   pre-match features built from the clean frames

    Everything is re-exported here, so from money_printer_research.schema import ... works for any model.

    Every column is F[...] (pandera FieldType) with a description, so pl.col(ScheduleCols.season) works and pyright types it as str. The dtypes are the ones the pipeline produces in memory. CSV loses some of them (season "1516" comes back as an integer), so read the CSVs with read_clean(), which applies the schema's dtypes, then validates.

    def read_clean(out_dir: Path, name: str) -> pl.DataFrame:
    """Read <out_dir>/<name>.csv with the schema's dtypes, then validate it."""
    schema = CLEAN_FILES[name]
    overrides = {n: col.dtype.type for n, col in schema.columns.items()}
    df = pl.read_csv(out_dir / f"{name}.csv", schema_overrides=overrides)
    return validate_lazy(df, schema, name)

    def check_clean() -> None:
    """Entry point `check_clean`: validate every clean CSV; exit 1 if any fails."""
    out = settings.clean.out_dir
    failed = 0
    for name in CLEAN_FILES:
        path = out / f"{name}.csv"
        if not path.exists():
            print(f"MISSING {path}", flush=True)
            failed += 1
            continue
        try:
            df = read_clean(out, name)
            print(f"ok      {name:15s} {df.height:>8,} rows", flush=True)
        except ValueError as e:
            print(f"FAIL    {e}", flush=True)
            failed += 1
    raise SystemExit(1 if failed else 0)

    money_printer_research.schema.collected ¶

    Checks for collected source files, and how raw models map to selected ones.

    Every entity has a raw.py and a selected.py:

    raw.py       every column of a source file as collected. Collection checks every
             column (check_collected), so a source that changes shape fails at
             download time, not halfway through cleaning.
selected.py  only the raw columns the clean pipeline reads, each copied line for
             line from raw.py (same annotation, nullability and description).

    Raw names are kept as they come from each source. Example values come from the files as collected for 2014/15 to 2025/26.

    def check_collected(path: Path, schema: RawSchema) -> None:
    """Raise ValueError if the file at `path` does not match every column of `schema`."""
    if path.suffix == ".parquet":
        df = pl.read_parquet(path)
    else:
        df = pl.read_csv(path, try_parse_dates=True)
    validate_lazy(df, schema.to_schema(), schema.__name__)

    def validate_lazy(df: pl.DataFrame, schema: pa.DataFrameSchema, name: str) -> pl.DataFrame:
    """Validate with every problem in one ValueError, as callers catch ValueError."""
    try:
        return schema.validate(df, lazy=True)
    except SchemaErrors as e:
        raise ValueError(f"{name}:\n{e.failure_cases}") from e
