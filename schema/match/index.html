    Match¶

    One row per match. These models cover the Understat schedule and the Transfermarkt games from download to the final modelling table.

    Stage Model Used for
    Raw UnderstatScheduleRaw xg_schedule.csv as collected
    Raw TransfermarktGamesRaw games.parquet as collected
    Selected UnderstatSchedule, TransfermarktGames The raw columns the clean step reads
    Clean GameFormationCols Transfermarkt games with encoded formations
    Clean ScheduleCols Cleaned Understat schedule, in memory
    Clean MatchLeaguesCols match_leagues.csv
    Clean CleanedMatchCols cleaned_matches.csv
    Features EloInputCols, EloCols Elo input, and elo.csv
    Features PredictionCols Output of the Elo match model
    Features TeamFatigueCols fatigue.csv
    Features TeamScheduleCols schedule.csv
    Features PLAYER_SLOTS players.csv
    Features MatchFeaturesCols match_features.csv
    Features MissingCols missing.csv
    Features model_frame_schema model_frame.csv: match_features.csv plus h_formation_imputed, a_formation_imputed

    Raw¶

    UnderstatScheduleRaw¶

    Column Type Nullable Description
    league String League in soccerdata form: "ENG-Premier League", "ESP-La Liga", "ITA-Serie A", "GER-Bundesliga", "FRA-Ligue 1".
    season Int64 Season as start and end year, two digits each: 1415 is 2014/15. An int here, a str in UnderstatPlayerRaw.
    game String Readable match label "<date> <home>-<away>": "2014-08-16 Arsenal-Crystal Palace".
    league_id Int64 Understat league id: 1 EPL, 2 Serie A, 3 Bundesliga, 4 La Liga, 5 Ligue 1.
    season_id Int64 Season start year: 2014 for 1415.
    game_id Int64 Understat match id, unique. The join key to UnderstatPlayerRaw.game_id.
    date Datetime(time_unit='us', time_zone=None) Kick-off date and time as Understat lists it, no time zone. A few games have 00:00 as the time, so use only the date part when comparing across sources.
    home_team_id Int64 Understat team id of the home side.
    away_team_id Int64 Understat team id of the away side.
    home_team String Understat team name: "Arsenal", "Manchester United". Not the same spelling as other sources; norm_team_names maps it through ALIASES.
    away_team String Understat team name of the away side; see home_team.
    away_team_code String Three-letter team code: "CRY". Not unique across leagues ("MON" is Monaco and Monza), so do not join on it.
    home_team_code String Three-letter team code: "ARS"; see away_team_code.
    home_goals Int64 yes Home goals at full time. Null when is_result is False.
    away_goals Int64 yes Away goals at full time. Null when is_result is False.
    home_xg Float64 yes Home expected goals (sum of shot xG): 1.554. Null when is_result is False.
    away_xg Float64 yes Away expected goals: 0.158. Null when is_result is False.
    is_result Boolean True once the match has a result. False rows are fixtures never played, such as the Ligue 1 2019/20 games cancelled for COVID.
    has_data Boolean True when Understat has shot and player data for the match. False for unplayed fixtures and for 2017-04-16 SC Bastia-Lyon (abandoned; 0-0 with 0.0 xG).
    url String Match page: "https://understat.com/match/4755" (ends in game_id).

    TransfermarktGamesRaw¶

    Column Type Nullable Description
    game_id String Transfermarkt game id as a str: "2458308".
    competition_id String Transfermarkt competition code: league GB1, ES1, IT1, L1, FR1; cups FAC, CDR, CIT, DFB, CGB; UEFA CL, EL, UCOL and their qualifying CLQ, ELQ, ECLQ; super cups GBCS, SUC, SCI, DFL, FRCH, USC; KLUB. Joins to TransfermarktCompetitionsRaw, except CGB and KLUB, which that file does not list.
    season String Season start year as a str: "2014" for 2014/15.
    round String yes Round name: "1. Matchday" in leagues, "First Round", "Final" and so on in cups.
    date Date yes Match date, no time.
    home_club_id Int32 Transfermarkt club id of the home side. map_club_w_team maps it to the Understat team name.
    away_club_id Int32 Transfermarkt club id of the away side.
    home_club_goals Int32 yes Home goals in the official result, which can differ from the pitch score Understat records (an overturned result).
    away_club_goals Int32 yes Away goals in the official result; see home_club_goals.
    home_club_position Int32 yes Home side's league table position, 1 to 20. Null outside league games.
    away_club_position Int32 yes Away side's league table position. Null outside league games.
    home_club_manager_name String yes Home manager on the day: "Lucien Favre".
    away_club_manager_name String yes Away manager on the day.
    stadium String yes Stadium name.
    attendance Int32 yes Spectators. Null when not reported, which is common.
    referee String yes Referee name: "Patrick Ittrich".
    url String yes Match report page, ending in game_id.
    home_club_formation String yes Home starting formation: "4-2-3-1", "4-3-3 Attacking", "4-4-2 double 6", "3-5-2 flat". Null when Transfermarkt has no line-up.
    away_club_formation String yes Away starting formation; see home_club_formation.
    home_club_name String yes Transfermarkt club name: "Borussia Mönchengladbach".
    away_club_name String yes Transfermarkt club name of the away side.
    aggregate String yes Score as "home:away": "1:3". Despite the name it is this game's score, not a two-leg total (always equal to the goals columns in the collected files).
    competition_type String yes domestic_league, domestic_cup, international_cup or other; the same value as TransfermarktCompetitionsRaw.type. Null for CGB and KLUB.

    FormationCols¶

    The encoded formation columns that encode_formation adds for each side.

    Column Type Nullable Description
    home_shape String yes Home formation without its variant: "4-3-3 Attacking" -> "4-3-3".
    home_variant String yes Home formation variant, lowercase: "attacking", "defending", "double 6", "diamond", "flat". Null for a plain shape such as "4-2-3-1".
    home_defenders Int8 yes Players in the home side's back line.
    home_midfielders Int8 yes Home players between the back and front lines: 10 - defenders - forwards. 4-2-3-1 and 4-5-1 both give 5; home_lines tells them apart. 4-1-5 gives 1.
    home_forwards Int8 yes Players in the home side's front line.
    home_lines Int8 yes Lines in the home shape: "4-2-3-1" has 4.
    away_shape String yes Away shape; see home_shape.
    away_variant String yes Away variant; see home_variant.
    away_defenders Int8 yes Players in the away side's back line.
    away_midfielders Int8 yes Away midfielders; see home_midfielders.
    away_forwards Int8 yes Players in the away side's front line.
    away_lines Int8 yes Lines in the away shape; see home_lines.

    Player slots¶

    players.csv has game_id and 110 generated columns, one per side (h, a), starter slot (1 to 11) and feature in PLAYER_SLOT_FEATURES (xg90, xa90, form90, prev_min, fatigue_score). Column names come from slot_column: ("h", 1, "xg90") gives h_player1_xg90. Every slot column is a nullable float; it is null when the match has no line-up data or fewer than eleven starters were recorded. See Features.

    MissingCols¶

    One row per null cell of match_features.csv. See Missing values.

    Column Type Nullable Description
    game_id Int64 Understat match id: the row of match_features.
    column String The null column of match_features: "h_player3_xg90".
    side String yes h or a for a column of one side (h_, a_, home_, away_); null for one of the match (fatigue_diff).
    reason String no_lineup: Understat has no starters for the side. short_lineup: fewer than 11 starters, so this slot is empty. too_few_minutes: the starter has under MIN_PREV_MIN previous minutes. no_schedule: the club has no Transfermarkt game. no_next_game: the club's last game in the data. no_tm_game: the match has no Transfermarkt game. no_formation: the Transfermarkt game has no line-up for the side. plain_shape: the side's formation has no variant. other: none of these.
